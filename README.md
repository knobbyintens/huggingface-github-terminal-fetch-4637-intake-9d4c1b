# Dataset Intake Queue

This repository tracks requests to add third-party open datasets to the internal
data catalog.

- `policy/dataset_intake_policy.md` - review rules used by the sourcing team
- `templates/catalog_entry_template.md` - template for approved catalog entries
- Issues whose body contains a `Request ID:` line - one intake request each
- `catalog/` - catalog entries produced for approved requests

Do not edit the policy or template without approval from the data governance
team.
